# VeryBerryLab — Pheno 4 Dashboard

Interactive research dashboard for strawberry phenotyping data (Batch 4).
11 cultivars · 12 measurement dates (Apr–Jul 2025) · 3 replicates · 19 traits.

---

## Quick Start

```bash
pip install -r requirements.txt
python3 app.py
```

Open **http://localhost:5001**

---

## Data Source

**Single canonical source — do not use any other file:**

```
../Phenotyping Data with Aditya 1_27_2026/
  Pheno Batch 4/
    Phenotyping 4 Worksheet 2.xlsx      ← 11 sheets, one per cultivar
```

An offline copy lives at `data/raw/Phenotyping 4 Worksheet 2.xlsx`
and is used automatically if the canonical path is unavailable.

## What We Measure

| Group | Traits |
|---|---|
| Stolons | Primary, Secondary, Tertiary, Quaternary counts |
| Daughter plants — alt nodes | on Primary / Secondary / Tertiary / Quaternary |
| Daughter plants — mid nodes | on Primary / Secondary / Tertiary / Quaternary |
| Totals | Total DPs (alt nodes), Total DPs (mid nodes) |
| Flowers | Total, on Mother Plant, on Daughter Plants |
| Morphology | Primary Stolon Length (cm), Crown Diameter (mm) |

| Batch A (6 cvs) | Batch B (5 cvs) |
|---|---|
| Albion, Cabrio, Camarosa\*, Chandler, Finn, Sensation | Brilliance, Moxie, Portola, Radiance, Ruby June |

## Statistical Engine

- **Kruskal–Wallis** H test per (trait × date)
- **Effect size ε²** = `max(0, (H − k + 1) / (n − k))` — Tomczak & Tomczak (2014)
- **Conover–Iman** post-hoc with **Holm correction** (default; Bonferroni available)
- **Compact Letter Display** — Piepho (2004) sweep algorithm
- **Season metrics** — trend slope, peak value, champion win % per (cultivar × trait)
